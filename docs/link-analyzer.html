网页链接分析器

内链外链 · 锚文本 · rel 属性 · 相对/绝对链接 · SEO 健康度评分（纯前端分析）

部分站点有防爬保护，可能抓取失败；失败时请改用「粘贴 HTML 源码」。

使用说明

  • 输入网址模式：抓取该网址的页面内容，并以它为基准解析所有相对链接；有防爬保护的站点可能抓取失败。
  • 粘贴源码模式：相对链接按原始路径展示；填写页面网址后可进一步识别内外链并解析相对链接。
  • 链接类型：内链（同域名）、外链（不同域名）、锚点 #、mailto/tel、JavaScript 链接、空链接。
  • href 书写方式：绝对链接、根相对（/path）、路径相对（../path）、协议相对（//cdn）。站内推荐根相对路径。
  • 常见问题：内链加 nofollow、空锚文本、图片链接缺 alt、target=_blank 缺 noopener、HTTP 混合内容、路径相对链接。
  • 状态检测：批量检查去重后的前 50 个 URL（HEAD 请求），2xx 正常 / 3xx 重定向 / 4xx·5xx 错误 / 0 无法连接。
所有分析均在浏览器本地完成，不会上传任何数据。
